# 🎹 Hızlı Klavye - Türkçe On Parmak Hız Testi

Modern ve sade bir **Türkçe On Parmak Klavye Hız Testi** uygulaması. Kurulum gerektirmez, doğrudan tarayıcıda çalışır ve mobil cihazlarla tam uyumludur.

---

## ⚡ Özellikler

- 🎯 **Farklı Kategoriler:** Sık kullanılan 200/1000 kelime, şehirler, uzun metinler ve kendi metnini ekleme imkanı.
- ⏱️ **Esnek Süreler:** 15, 30, 45 ve 60 saniyelik test seçenekleri.
- 🔤 **Anlık Hata Analizi:** Doğru ve yanlış basılan harfleri renkle gösterme ve test sonunda harf bazlı hata raporu.
- ⏸️ **Mola Modu:** `ESC` veya seçtiğiniz kısayol tuşu ile testi dondurma.
- 🎨 **Tema Seçenekleri:** Koyu Mod, Açık Mod ve Sistem Teması.
- 🔊 **Tuş Sesleri:** Daktilo ve Mekanik Klavye ses efektleri.
- 📊 **Detaylı İstatistikler:** WPM, DKS (vuruş/dk), doğruluk oranı ve anlık gelişim grafiği.
- 💾 **Veri İndirme:** Skor geçmişini **JSON** veya **CSV (Excel)** dosyası olarak indirme.

---

## 🚀 Kullanım

1. Depoyu klonlayın veya zip olarak indirin.
2. `index.html` dosyasını tarayıcınızda açın.

> **GitHub Pages:** Depo ayarlarından (`Settings > Pages`) `main` branch'ini seçerek siteyi ücretsiz canlıya alabilirsiniz.

---

## 🛠️ Teknolojiler

- HTML5 / Tailwind CSS / Vanilla JavaScript
- Chart.js (Grafikler) & Web Audio API (Sesler)
